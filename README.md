# Portfólio Criativo

Site frontend do portfólio de **Ivy Techart** (Design de Mídias Digitais, Marketing e UI/UX). Feito só com HTML, CSS e JavaScript, sem build, para publicar no GitHub Pages.

## Como ver localmente

Abra o arquivo `index.html` no navegador, ou suba um servidor simples na pasta do projeto:

```bash
npx serve .
```

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (por exemplo `portfolio`).
2. Envie estes arquivos para a branch `main`.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha:
   - Source: **Deploy from a branch**
   - Branch: `main`
   - Folder: `/ (root)`
5. Salve. Em alguns minutos o site fica em:

`https://ivycosta-ship-it.github.io/Portf-lio/`
